# TalentSphere Frontend

Frontend-only hackathon MVP for **TalentSphere — AI-Powered Career & Talent Ecosystem**.

## Included
- React + Vite
- React Router
- Lucide React
- Recharts
- Responsive premium SaaS UI
- Mock/static data only
- No Node/Express backend
- No MongoDB
- No API keys
- Functional frontend interactions: quiz, roadmap completion, matching demo, filters, practice test, AI interview demo, workforce dashboard

## Run in VS Code

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The entire application is frontend-only and intentionally uses seeded demo data/local React state.
